 ⛏️ Albion Gather Bot

Автоматический бот для сбора ресурсов в Albion Online с распознаванием экрана.

 🎯 Возможности

- ✅ Распознавание ресурсов по цвету — бот сам находит деревья, руду, камень, траву
- ✅ Калибровка в 1 клик — наведи мышь на ресурс и нажми клавишу
- ✅ Автоматический поворот камеры — если ресурсы не видны, бот осмотрится
- ✅ Движение вперёд — опционально, для поиска новых ресурсов
- ✅ Рандомные задержки — имитация человеческого поведения (анти-детект)
- ✅ Настраиваемый допуск по цвету — подстройка под любое освещение
- ✅ Автономный .exe — не требует установки .NET или Visual Studio

 🚀 Установка

 Из GitHub Release (для пользователей):
1. Скачай последний релиз со страницы [Releases](https://github.com/Pan1cxz/AlbionGatherBot/releases)
2. Распакуй `AlbionGatherBot_v1.0.zip` в любую папку
3. Запусти `AlbionGatherBot.exe`

🎮 Как использовать
Запусти Albion Online в оконном режиме
Подведи персонажа к ресурсам (лес, рудник, каменоломня)
Запусти AlbionGatherBot.exe
Нажми "🎯 КАЛИБРОВАТЬ" → наведи мышь на ресурс в игре → нажми любую клавишу
Нажми "▶ ЗАПУСТИТЬ"
Бот начнёт автоматически собирать ресурсы!
